# Project instructions
Build a local, automated 2D cutout comedy production pipeline. Read capstone.md for architecture, progress.md for current state, bible/ for narrative context and assets/reference/ for visual references. Preserve original reference artwork and episode guides. Use original recurring characters; keep proportions, colors and voices consistent. Prefer deterministic SVG rigs and Python compositing, with Kokoro, Rhubarb and FFmpeg; diffusion video is optional for special sequences. Use uv for Python dependencies where practical. Target Windows 11 / WSL Ubuntu 24.04 with RTX 3090 24 GB; optional Ollama backend on Mac mini. Verify installed tools and model licenses before relying on them. Keep generated video/audio and model weights out of Git. Update progress.md after meaningful work, recording actual tests, decisions and blockers. Do not commit or push without approval.
